# Grammar Sprint

English-language, iPad-friendly exam trainer for **RUB Grammar BM, Sommersemester 2026**.

## Open online

**GitHub Pages:** <https://sirmrba.github.io/grammar-sprint-sidelya/>

The source is stored in the private repository <https://github.com/SirMrBA/grammar-sprint-sidelya>. The published GitHub Pages website itself is public.

## Contents

- 130 rule flashcards across all official topics
- 175 Moodle-style practice questions with explanations and reader references
- 35 free-response translation prompts with model answers and grammar targets
- 85-item, 100-point mock exam using the official 15/20/15/10/15/25 point split
- saved mistakes, card ratings, study-plan checkboxes and mock history
- 6-page Last-Minute Guide PDF
- 21-page Complete Exam Guide PDF
- installable PWA with offline caching after the first successful load

## Start on the Mac

Double-click **Start Trainer.command**. Keep the Terminal window open while the trainer is in use.

The script prints the current Wi-Fi address, starts the trainer on port `8766` and opens it on the Mac. An iPad must be connected to the same Wi-Fi network to use the local address.

## Stop

Press **Ctrl+C** in the Terminal window or close that Terminal window.
